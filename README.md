# student-debt-of-doctors-minimal
Stata code for Student Debt of Doctors. Refer to https://gitlab.com/simon-hhs/student-debt-of-doctors.

## Why are there two code masterfiles?
Code is run in two masterfiles, 00A-master-data.do and 00B-master-analysis.do. There is an intermediate step of running Claude Work to Identify Cohorts/run.bat that separates them.

## Where is the data for this project?
You will need access to Dropbox/Student Debt of Doctors folder for the raw data and working data.
